
# Voice AI Translator

GitHub Upload Package

Steps:
1. Upload all files to GitHub repository.
2. Add whisper.cpp source files.
3. Add Whisper model:
   app/src/main/assets/models/ggml-base.bin
4. Run GitHub Actions build.

Features target:
- Voice recording
- Speech to text
- Persian
- English
- Chinese
- Arabic
- Turkish
